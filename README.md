# Claude Portfolio — Rythm Jagga

A literary-journal-style portfolio and CMS built with **Next.js 14 (App Router)**, **Tailwind CSS**, **Framer Motion**, and **next-themes**.

- **Design System:** Newsreader serif typography, terracotta accents, warm ivory light mode, and deep burgundy dark mode.
- **Intro Experience:** Terminal typewriter status animation with Claude vector mark.
- **Studio CMS:** Real-time dashboard for managing profile, skills, experience, projects, screenshots, and essays.
- **Writing & Blog:** Deep essay reader with pull quotes, code blocks, and cover art.
- **Projects Showcase:** Responsive cards with screenshot previews, live links, and direct GitHub links.

## Quick Start

```bash
# Install dependencies
npm install

# Run portfolio dev server (port 3000)
npm run dev

# Run dashboard CMS (port 3001)
cd dashboard && npm run dev
```

Open [http://localhost:3000](http://localhost:3000) for the portfolio and [http://localhost:3001](http://localhost:3001) for the Studio CMS.
